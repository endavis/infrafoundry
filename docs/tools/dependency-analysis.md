# Dependency Analysis

## Overview
The Dependency Analysis tool visualizes and analyzes dependencies between infrastructure resources. It helps understand the impact of changes and the order of operations.

## Usage

```bash
infra dependencies --env dev
```

## Features
- Visualize dependencies as a graph (Mermaid format).
- Analyze critical paths.
- Identify circular dependencies.
- Filter by specific resource to see its dependents and dependencies.
