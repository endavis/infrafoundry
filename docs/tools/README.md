# InfraFoundry Tools

This directory contains documentation for the various utility tools included in InfraFoundry.

- [Config Diff Tool](config-diff.md): Compare configurations between environments.
- [Dependency Analysis](dependency-analysis.md): Analyze resource dependencies.
- [OPNsense Parser](opnsense-parser.md): Tools for OPNsense configuration.
- [Proxmox Exporter](proxmox-exporter.md): Export existing Proxmox infrastructure to YAML.
